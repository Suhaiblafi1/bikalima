# الأدوار والصلاحيات

## الموجود

الأدوار الحالية: `admin`، `supervisor`، `trainer`، `student`، `sales`، `parent`. التحقق موجود في الخادم لكنه خشن ويعتمد غالباً على الدور فقط.

## النموذج المستهدف

`Role + Permission + Resource + Action + Scope + Ownership + Status + Policy`

المبادئ: Deny by default، Least privilege، Separation of duties، Server-side enforcement.

## قواعد الانتقال

- لا يختار المستخدم دور مدرب أو مدير عند التسجيل.
- المدير الأعلى ليس تطابق بريد؛ هو تعيين موثوق ومؤكد ومسجل.
- المدرب يرى طلاب دوراته فقط.
- كل endpoint حساس يحدد `resource/action/scope` ويملك اختبار منع سلبي.
- تغيير الدور أو الصلاحية يسجل القيمة السابقة والجديدة والسبب والجلسة.
