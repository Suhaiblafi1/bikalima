# مصفوفة تقاطع خطة LMS مع الموجود

| المجال | الحالة | القرار التنفيذي |
|---|---|---|
| المصادقة والتسجيل | منجز | اختبار وتقوية فقط |
| استرداد كلمة المرور وتأكيد البريد | منجز | لا يعاد البناء |
| CRM | منجز بقوة | لا يعاد البناء |
| CMS والصفحات والسياسات | منجز بقوة | تحسين UX فقط |
| لوحة الطالب | منجز جزئياً بقوة | اختصار وتنظيم وتحسين الحالات |
| لوحة المدرب | جزئي | تقسيم العمل اليومي وإكمال الصلاحيات |
| لوحة الإدارة | منجز بقوة | كثافة، بطاقات هاتف، وإجراءات آمنة |
| بوابة ولي الأمر | منجز | الحفاظ والتحسين |
| إدارة الدورات | جزئي قوي | إضافة workflow/versioning فوق الموجود |
| كتالوج دورات عام | جديد فعلاً | موجة التحويل |
| ملفات مدربين عامة | جديد | بعد الإطلاق |
| طلب انضمام مدرب | جديد فعلاً | MVP بعد الأساسات الأمنية |
| RBAC دقيق Resource/Action/Scope | جزئي/جديد | توسيع تدريجي مع توافق الأدوار الحالية |
| Course Builder | جزئي قوي | Tabs، مراجعة، وحالات نشر |
| مشغل التعلم | جزئي قوي | توحيد المشغلين وتحسين الهاتف والأخطاء |
| الجلسات وZoom | جزئي | Provider + Webhooks + Calendar لاحقاً |
| الحضور | منجز جزئياً | فرض enrollment active ومنع التكرار |
| الواجبات والتسليم | جزئي | حالات كاملة، ملفات، Rubrics واعتراض |
| الاختبارات | جزئي محدود | نقل التصحيح للخادم أولاً ثم بنك أسئلة |
| مشاريع التخرج | جديد | V1، وليس موجة الإطلاق |
| الشهادات | جزئي قوي | Eligibility + Approval + إصدار غير قابل للتعديل الصامت |
| الرسائل | منجز جزئياً | تفضيلات وضوابط وإشعارات أفضل |
| الإشعارات | منجز جزئياً | Notification Preferences جديد |
| الدفع والخصومات | منجز جزئياً وقوي | لا يعاد البناء؛ تحقق واختبار فقط |
| التحليلات | جزئي | تقارير تعلم وإدارة مع الخصوصية |
| Audit Log | جزئي | توسيع وتحصين |
| Approval Engine | جديد | V1 بعد RBAC ونموذج البيانات |
| Support Tickets/Moderation | جديد | موجة التوسع |
| SCORM/xAPI/LTI/Open Badges | مؤجل | لا ينفذ الآن |
