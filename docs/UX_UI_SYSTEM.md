# نظام UX/UI والكثافة البصرية

## الأساس الموجود

الهوية الحالية دافئة: أخضر أساسي، ذهبي للتمييز، Tajawal للنص وNoto Naskh Arabic للعناوين، مع Tokens للألوان والظلال ونصف القطر. نحافظ عليها ونضيف نظام كثافة موحداً.

## قواعد الكثافة

- Hero هاتف: الإجراء الرئيسي داخل الشاشة الأولى، والارتفاع المستهدف 620–760px حسب المحتوى.
- Section هاتف: غالباً `40–56px` رأسياً، لا `64–96px` افتراضياً.
- Card هاتف: `16px`، ومريح `20px`؛ لا `32–48px` إلا لسبب.
- النص الأساسي 16px، الثانوي 14px، الوسوم 12px على الأقل.
- هدف اللمس 44×44px على pointer coarse؛ variant كثيف صريح للفأرة فقط.
- الحقول والأزرار والقوائم 44px على الهاتف.
- لا جدول سطح مكتب داخل الهاتف للمهام الأساسية؛ بطاقة بثلاثة حقول وإجراء أساسي وقائمة ثانوية.

## Progressive Disclosure

- الرئيسية: Hero/Trust → Why+Stats → البرامج → الحضوري → CTA. باقي المحتوى Teasers مع روابط About/Gallery/Library.
- المعرض: 8 صور أولاً ثم تحميل المزيد.
- المكتبة: 6 عناصر لكل تصنيف ثم عرض المزيد.
- المدرب: «اليوم» ثم Tabs للعمل التفصيلي.
- محرر الدورة: أساسي، التسعير، المحتوى، SEO، النشر.
- النماذج الطويلة: Stepper، ملخص قابل للطي، وإجراء ثابت لا يحجب المحتوى.

## ميزانيات طول مستهدفة عند 390px

| الصفحة | قبل | الهدف |
|---|---:|---:|
| الرئيسية | 20–22 شاشة | ≤12 شاشة |
| About | 8.2 | ≤5.5 |
| Gallery | 12.4 | ≤7 |
| Program | 3.2 | 3–4، يحافظ عليه |

## Breakpoints المطلوبة

320، 360، 375، 390، 430، 768، 1024، 1440. عند 768 لا يطبق min-height الخاص بتخطيط Desktop قبل بدء عمودين عند `lg`.

## الوصول

Focus ظاهر، Reduced Motion، Dialog صحيح مع focus trap، Skip Link، Labels، تباين WCAG AA، Logical Properties، Safe Area، تكبير 200%، وعدم الاعتماد على اللون وحده.
